Mathematical Calculator

🟡 In Development · v1.5
Started 2026 · Python · Kivy · Android

The Idea

This started as a question, not a plan. I wanted to know what I could actually build using just my phone — no laptop, nothing fancy. Coding felt fun and exciting from the first line, and I didn't want to stop once I started. I kept questioning how far a phone-only setup could really go, and this calculator became the answer.

The Journey

Builds #1–12
❌ "Can we even build this thing?"

The Android build environment was being established and repeatedly debugged.

Builds #13–18
✅ "Yes. We have a working APK."

First stable build period — progressed through Version 1.2 and Version 1.4.

Build #19
💥 "We broke the development state."

The Version 1.5 development state crashed and became unusable.

Build #20
🔄 "Recover the working version and continue."

The working #18 state was restored and became the foundation for Version 1.5.

Builds #21–31
❌ "Version 1.5 is great, but Android is fighting us."

A major Android dependency and build-compatibility battle.

Builds #32–40
✅ "Build system stabilized. Now we can actually develop."

The pipeline stabilized and real Version 1.5 feature development resumed rapidly.

Builds #42–43
🚀 "Back to serious feature development."

Advanced-mathematics dependencies were added and camera scanning was successfully introduced.

Current — Recovery-v1.5
🔥 Scientific + Advanced Math + Symbolic Math + Graphing + Steps + Camera Scanning

Continued roadmap development.
