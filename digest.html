Digest

🟡 In Development · Runs Locally
Started Oct 2026 · Python · SQLite · RSS

The Idea

A personal news reader that collects articles from the feeds I choose and keeps them in one place. It was built and runs on my phone in Termux, with no cloud service involved.

How It Works

FetchingReads every enabled RSS feed, cleans up the text and saves new articles to a local SQLite database. Duplicates are skipped and feed errors are recorded.
Why it mattersMatches keywords such as security, pricing or deprecated and attaches a short note about why the article is worth reading. If nothing matches, it stays silent.
Local appA small web app with templates shows the collected articles, plus scripts to fetch, run and back up the data.

The Journey

This is a working tool that I keep improving as I use it. It lives on my own device, so there is no live demo, but the code is on GitHub.

The "why it matters" notes are rule-based on purpose. A missing note is better than a generic one.
