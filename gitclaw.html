gitclaw

🟡 Experiment · Built on pi-mono
Started Oct 2026 · GitHub Actions · DeepSeek

The Idea

A personal AI coding assistant that lives entirely inside a GitHub repository. There is no server to run: you talk to it through GitHub Issues, and GitHub Actions does the work.

How It Works

Open an issueThe agent reads the request and replies as a comment.
Keep the conversation goingComment on the issue and the agent resumes the same session with its earlier context.
The repo is the memorySessions and any changes the agent makes are committed back to the repository.
Locked downOnly the repository owner, members and collaborators can trigger it.

Credit

This is my own setup of an existing idea. gitclaw is built on top of pi-mono by Mario Zechner, and mine is configured to use the DeepSeek model.

What I Learned

A whole assistant can run without any server of my own. GitHub provides the trigger, the compute and the storage.
