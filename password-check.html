Password Check

🟢 Live · Experiment
Started Oct 2026 · HTML · CSS · JavaScript

The Idea

Type a password and see how long a normal graphics card would need to crack it by brute force. It is a quick way to see why length matters more than clever symbols. Nothing leaves the page: no network requests and no storage.

What It Does

Time to crackEstimated at 10 billion guesses per second, shown either as exact units or in plain words like "a lifetime".
The numbersLength, character set size, entropy in bits and worst-case guesses.
Common passwordsInstantly flags passwords found in a list of about 200 of the most leaked ones.
Pattern warningsCalls out short passwords, repeated characters, years, digits-only and keyboard sequences.

What I Learned

Estimates like this are a best case for the defender. Real attackers use many GPUs and smart wordlists, so real crack times are often much shorter.
