Student Study Companion

🟡 Early Development · Web PWA
Started 2026 · HTML · CSS · JavaScript · PWA

The Idea

A study tool built around the things a student actually needs during a study session: knowing what to work on, staying focused, and keeping useful notes without needing a collection of separate apps.

Current Prototype

Study tasksAdd, complete, and clear tasks for the current study session.
Focus timerA simple study timer that can be started, paused, and reset.
Quick notesKeep short notes locally on the device while studying.
Offline-firstThe prototype is designed to keep working after the PWA has been installed and cached.

The Journey

This is deliberately an early build. The goal is to use the prototype first, find what is genuinely useful, and let the next features come from actual study needs instead of filling it with features just because they sound impressive.

The archive will be updated as the project becomes more defined.

What I Learned

Start with something usable. A project does not need its entire future planned before the first useful version exists.
